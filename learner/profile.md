# 学习者档案

## 已知目标

- 系统学习并深入理解 Java 后端八股。
- 学习后端通用八股。
- 学习当前主流 AI Agent 应用开发相关八股。
- 主要阅读来源是 JavaGuide 及其 AI 应用内容。

## 默认偏好

- 默认语言：中文。
- 学习目的：理解原理、形成面试表达、能够承受追问。
- 学习方式：阅读 JavaGuide 时随时提问，再通过追问和复习巩固。
- 模型偏好：日常学习不绑定具体模型，应兼容轻量、低成本、较旧或本地模型；通过最小上下文、小步拆分、固定结构和交付前自检提高质量，不默认依赖高性能模型。

## 尚未确定

- Java 和后端实际基础。
- 工作年限或目标岗位级别。
- 面试时间计划。
- 目标公司和面试侧重点。
