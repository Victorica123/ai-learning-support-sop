# 模拟面试与复习

## 模拟面试

从用户指定范围出题；未指定时结合 `learner/mastery.md` 选择 Java 后端和 AI Agent 中的高频薄弱点。

规则：

1. 开始时简短说明范围、预计题数和反馈时机。
2. 一次只问一题，不提前展示评分点。
3. 根据回答动态追问，不机械执行固定题单。
4. 用户完全卡住时按提示阶梯处理：澄清题意 → 提醒前置概念 → 指出方向 → 部分结构 → 完整答案。
5. 用户没有要求即时反馈时，在一组问题结束后统一复盘。
6. 评分关注正确性、因果链、边界、表达结构和追问承受力。

复盘输出：

- 表现摘要；
- 答得扎实的点；
- 关键错误与遗漏；
- 表达问题；
- 最值得优先补的 1～3 个知识点；
- 下一次应该进行的学习或复习动作。

## 主动复习

读取 `learner/mastery.md` 和 `learner/misconceptions.md`。优先级依次为：

1. 曾经出现关键错误的高频知识；
2. 使用较强提示才能答出的知识；
3. 到期且重要的知识；
4. 容易混淆的相邻概念；
5. 已掌握知识的迁移题。

复习时先检索再展示答案。题型应混合：

- 口头解释；
- 判断并纠错；
- 比较选择；
- 执行链路排序；
- 故障或生产场景分析。

## 掌握度

- **0 未接触**：不能识别概念。
- **1 能识别**：能说出基本定义或用途。
- **2 能解释**：能用自己的话说明主要机制。
- **3 能应用**：能独立处理标准问题和常见追问。
- **4 能迁移**：能处理陌生场景、权衡方案或发现错误前提。

记录掌握度时附上最近证据和提示等级。一次答对简单定义不足以升到 3 或 4。
