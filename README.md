# Java 后端与 AI Agent 八股学习 SOP

这个目录让 AI 按稳定的教学流程，辅助学习 JavaGuide/AIGuide 中的 Java 后端、后端通用和 AI Agent 八股知识。

它不是课程网站，也不是待开发的应用。打开本目录与 Codex 对话，就可以直接使用自然语言学习。

## 最常见的使用方式

| 你正在做什么 | 可以直接这样问 |
|---|---|
| 阅读 JavaGuide 时没看懂一句话 | `JavaGuide 这里说 volatile 保证可见性，这句话具体是什么意思？` |
| 想追到底层原理 | `为什么 ConcurrentHashMap 的读操作通常不需要加锁？深入讲一下。` |
| 想整理面试表达 | `MySQL 为什么用 B+ 树？面试时怎么回答？` |
| 混淆相似概念 | `缓存穿透、击穿和雪崩到底怎么区分？` |
| 检查自己的答案 | `这是我对 Spring 事务失效的回答，帮我判断哪里不准确：……` |
| 让 AI 模拟追问 | `围绕线程池面试我，先不要给答案。` |
| 学习 Agent 八股 | `我在看 JavaGuide 的 Agent Loop，帮我理解它和普通 Workflow 的区别。` |
| 复习薄弱点 | `复习最近学过的 JVM 和 RAG，优先考我答错过的。` |

不需要严格使用“学习：”“单题：”等格式。只要表达当前问题和期望深度，SOP 会自动选择模式。

## 使用不同能力的模型

这套 SOP 不绑定 Luna、Sol 或其他具体模型。轻量模型、低成本模型、较旧模型和本地模型都使用同一套流程与质量标准；区别主要体现在复杂问题会被拆得更细、需要更多轮完成。

SOP 能显著提高较弱模型的输出下限与稳定性，但不能保证任何模型都与高性能模型完全等价。它重点弥补的是漏步骤、结构混乱、上下文过载、概念混淆和缺少自检，无法凭空补充模型没有的知识、上下文容量或工具能力。

为了让模式判断更稳定，可以选择在问题前加一个短口令：

| 短口令 | 适用情境 | 示例 |
|---|---|---|
| `解释：` | 快速弄懂一句话或一个概念 | `解释：为什么 String 是不可变的？` |
| `深挖：` | 理解底层机制、执行链和边界 | `深挖：Spring 事务传播机制。` |
| `面试：` | 形成可口述回答并准备追问 | `面试：MySQL 为什么使用 B+ 树？` |
| `对比：` | 辨析易混概念 | `对比：synchronized 和 ReentrantLock。` |
| `批改：` | 检查自己的答案 | `批改：我认为 volatile 能保证线程安全，因为……` |
| `考我：` | 一次一题进行检索练习 | `考我：Java 线程池。` |
| `复习：` | 根据学习记录检查薄弱点 | `复习：最近的 JVM 内容。` |

短口令不是必需语法，自然语言仍然有效。能力较弱的模型遇到大问题时会先拆成小问题，例如先解释 Agent Loop，再对比 Workflow，最后进行面试追问，而不是一轮内同时覆盖整个 Agent 知识图谱。

### 可选的高稳定输入卡

平时直接提问即可。如果发现某个模型经常答偏，可以多提供下面四项；不清楚的项目可以省略：

```text
主题：正在学习的知识点
材料：JavaGuide 链接、原文或代码
卡点：具体哪句话或哪一步不理解
目标：快速解释 / 深挖原理 / 面试表达 / 批改 / 考我
```

例如：

```text
主题：ThreadLocal
材料：JavaGuide 中 ThreadLocalMap 的 key 使用弱引用这一节
卡点：为什么 key 回收后 value 还可能泄漏
目标：深挖原理，并给一道检验题
```

推荐把一轮输入控制为“一个知识点 + 一个学习目标”。SOP 会按“锁定问题 → 选择最小材料 → 建立因果链 → 按模式输出 → 交付前自检”执行。跨多个专题的综合推理、很长材料的整体审校或长场次全局复盘，即使拆分后仍可能受益于更强模型。

## 阅读 JavaGuide 时的推荐流程

1. 正常阅读 JavaGuide/AIGuide。
2. 遇到不理解的句子、图或代码，直接粘贴内容或发送页面链接。
3. 先解决眼前疑问；需要时继续说“再深入一点”“从源码解释”“面试怎么说”或“追问我”。
4. 看完一个小节后说：`根据刚才这部分考我 3 道题。`
5. 学完一个专题后说：`模拟面试：Java 并发，20 分钟。`
6. 以后说：`复习到期内容。`，AI 会优先检查薄弱点和旧误区。

## SOP 提供的模式

- 即时澄清：回答文章中某一句或某个概念。
- 深入理解：建立机制、执行链路、边界和反例。
- 面试表达：生成 30 秒回答、深入版回答和追问链。
- 对比辨析：围绕相同维度比较易混概念。
- 回答批改：先评价你的原回答，再给改进版本。
- 模拟面试：一次一题、动态追问、结束后复盘。
- 主动复习：闭卷检索、错题重测和掌握度更新。

## 学习是否完成

“看懂了”不作为掌握证据。一次有效学习至少应出现一种可观察结果：

- 你能用自己的话解释机制；
- 你能回答一个追问；
- 你能判断适用场景或反例；
- 你能分析代码、执行链路或故障现象；
- 你能把概念迁移到一个新问题。

学习状态保存在 `learner/`，不会因为更换对话而完全丢失。
